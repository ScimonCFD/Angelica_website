User Guide

From a blank canvas to a solved network.

Everything you need to build, configure, and run a pipe-network simulation in Angelica — nodes, links, devices, settings panels, and the built-in tutorial suite.

Getting started

Launching the GUI

After installation, start the graphical interface from a terminal or command prompt. On Windows you can also use the Start-menu shortcut created by the installer.

Linux / macOS (pip install)

angelica-gui

or equivalently:

python -m angelica.gui

Windows (installer)

Double-click the Angelica shortcut in the Start Menu. The installer creates the shortcut automatically — no command is needed.

The main window opens with an empty canvas, a left-side settings panel, and a toolbar at the top. The window title shows the name of the currently open file (or Untitled for a new scene).

The drawing area

The canvas

The large central area is the canvas — a free-form drawing surface where you build your pipe network by placing nodes and drawing links between them.

  • Zoom — scroll the mouse wheel to zoom in and out. Node icons and labels scale with the zoom level.
  • Pan — click and drag the canvas background with the middle mouse button to pan the view.
  • Select & move a node — left-click to select (highlighted); drag to reposition. Press Delete or Backspace to remove the selected node and all its connected links.
  • Draw a link — right-click (or Shift+left-click) a node and drag to another node to draw a connection.
  • Edit or delete a link — right-click any link to open a context menu with Edit Components, the result plots that apply (Pressure Profile, Temperature Profile, Phase Envelope), and Delete Connection.
  • Undo / Redo — Ctrl+Z / Ctrl+Y (or Edit → Undo / Redo) step back and forward through node placements, link additions, link deletions, and node moves.
  • Save / Open — use File → Save (Ctrl+S) and File → Open. Scene files (.gui.json) store the full scene and, when results exist, the last solve output so you can reopen and export without re-running. Tutorial files are read-only; use Save As… to save a copy elsewhere.

Network topology

Nodes

Every network is a graph of nodes connected by links. Angelica has three node types. Click the corresponding button in the Node Palette on the left (▲ source, ▼ sink, ○ junction), then click the desired position on the canvas. Double-click a node to edit its properties.

Source

A boundary inlet node. You specify either the static pressure at this node or the total mass flow rate entering the network here. With heat transfer, it also takes the inlet temperature. In black-oil cases it carries the stream's GOR and WOR (and, optionally, its own API and gas gravity); in compositional cases, its mole fractions. A source or sink connects to exactly one link — use a junction to split or merge flows.

Sink

A boundary outlet node. Like a source, you specify either pressure or mass flow rate. Its thermal condition defaults to zero gradient (the fluid leaves at whatever temperature arrives). Sources and sinks can carry flow in either direction if the pressure field requires it.

Junction

An internal node where two or more pipes meet. No boundary condition is applied here — the solver enforces mass continuity (the sum of all mass flows entering equals the sum leaving). Pressure at junctions is a result, not an input.

Minimum requirement: at least one source or sink must have a specified pressure. This anchors the absolute pressure level of the solution. A network with only flow-specified boundaries is under-determined (infinite pressure solutions exist).

Links

A link is a directed connection between two nodes. To draw one, right-click (or Shift+left-click) the start node and drag to the end node.

The direction you draw the link sets the positive-flow convention displayed in results. The solver can return negative flow values if the actual flow direction is opposite to the one you drew.

Right-clicking any existing link opens a context menu:

  • Edit Components — open the properties dialog to add, reorder, delete, and configure devices.
  • Pressure Profile — pressure versus distance along the link (after a solve).
  • Temperature Profile — temperature versus distance (cases with heat transfer).
  • Multiphase Flow — per pipe segment: flow pattern, no-slip liquid fraction and in-situ holdup, superficial velocities, liquid volume, the elevation / friction split of the pressure gradient, and the API RP 14E erosional-velocity ratio vm/Ve (black-oil and compositional cases). Links above the erosional velocity are labelled in red on the canvas; links carrying free water colder than the hydrate formation temperature are labelled "HYD +x K" (compositional: van der Waals–Platteeuw on the composition; black-oil: gas-gravity chart).
  • Phase Envelope — bubble and dew curves of the fluid in this link, the critical point, constant vapour-fraction lines you can add, the gas-hydrate formation curve (optional: tick Hydrate curve), and the link's inlet and outlet conditions (compositional cases). Inlet and outlet are always drawn, also when they lie far outside the envelope.
  • Delete Connection — remove the link (undoable).

Double-clicking a link opens the Pressure Profile directly when results are available, or the Edit Components dialog otherwise.

Every node must be connected to at least one link, and the network must be fully connected (no isolated sub-graphs). Angelica checks both conditions before running and shows an error listing any problems.

Network devices

Devices inside a link

Each link holds an ordered list of devices in series — the outlet of one feeds the inlet of the next. Add them from the palette in the Edit Components dialog. Lengths, diameters, roughness and elevation are entered in the active unit system.

DeviceAvailable inWhat it does and its main inputs
PipeAll modesStraight pipe: length, internal diameter, elevation change (outlet minus inlet), roughness, number of segments for the profile plots. With heat transfer it also takes an overall U and ambient temperature, or a layered wall (inner film, steel wall, insulation, outer film).
FittingAll modesLocal loss ΔP = K·½ρV², with K typed in or picked from a library of 24 presets (elbows, return bends, tees, unions and valves).
PumpAll modesHead–flow curve, one Q H pair per line (Q in m³/h, H in m). One point gives the EPANET three-term curve; two or more are interpolated. Shaft work heats the fluid in thermal cases.
ChokeAll modesRestriction orifice: pipe and orifice diameters, discharge coefficient. Two-phase flow uses the Sachdeva model, including critical (choked) flow.
Check valveAll modesK-factor fitting (K = 2 when open) that closes when the downstream pressure is higher, so it never passes reverse flow.
SeparatorBlack-oil, compositionalLiquid outlet of a separator. The connection's start node is the separator: the streams arriving there are split at its pressure and temperature (black-oil: oil with its dissolved gas, free gas, water; compositional: equation-of-state flash with free water). The outlet takes the liquid (oil + water), the oil (with a water outlet: three-phase separator) or the water (alone: free-water knockout); the gas leaves through the node's other connections or its pressure boundary. Its flow is set by the split — it stands for the level-control valve — and its pressure drop is reported; a negative drop means the liquid needs a pump. Put it first in its connection. The results list each separator's gas, oil and water masses and standard rates. If a gas line flows back into the separator (its boundary above the separator), the fluid entering is taken as the separator's own gas unless a fluid is declared at that boundary, and the separator's message says so; into a vessel with no gas phase such a back-flow has no steady state and the run is reported as not converged.
RegulatorBlack-oil, compositionalPressure regulator. "Holds: downstream" is a pressure-reducing regulator that keeps the node after it at the set pressure; "upstream" is a back-pressure regulator that keeps the node before it at the set pressure (e.g. a separator, when put first on the separator's gas connection). While it can hold the set pressure it passes whatever flow that needs; when it cannot it is wide open (a fitting with the wide-open K, 5 unless set) or closed. Flow passes from the connection's start to its end only. The node it holds must not be a source or sink.
CompressorCompressible, black-oil, compositionalGas compressor specified by a pressure ratio, a pressure rise or a shaft power, with an isentropic or polytropic efficiency. Discharge temperature and power follow the gas's own isentrope (∫v·dP along the fluid's equation of state); it does not run backwards. Power and ratio are shown on the canvas after a run.
Heat SourceThermal modesHeater or cooler, either with a fixed duty in W (positive heats, negative cools) or set by its outlet temperature: the solver finds the duty, up to an optional maximum duty (beyond it the result says "duty limited"). The duty and outlet temperature are shown on the canvas and exported. Pressure drop rated at a reference flow, or fixed.
Well IPRBlack-oil, compositionalReservoir inflow between a reservoir node and the wellhead: productivity index J (m³/d/bar) with a linear or composite-Vogel IPR, or C and n of a Fetkovich (oil) or back-pressure (gas) law q = C·(P_r² − P_wf²)ⁿ. Reservoir pressure is the upstream source pressure. In compositional cases the standard gas and oil volumes come from a flash of the stream to standard conditions.
WellBlack-oil, compositionalReservoir inflow (linear, Vogel, Fetkovich or gas back-pressure IPR) plus production tubing (length, vertical rise, diameter, roughness). The tubing is integrated with Beggs-Brill, Hagedorn-Brown (oil wells) or Gray (gas wells), giving the well's deliverability curve; if the wellhead pressure is above the curve's maximum the well is dead. The fluid cools on the way up by heat loss to the formation (Ramey's model: geothermal gradient, formation conductivity and diffusivity, time on production, optional wellbore U), and the wellhead node shows the flowing wellhead temperature. In compositional cases (gas and gas-condensate wells) the well's fluid is flashed once on a pressure–temperature table and interpolated along the tubing. A dead well is reported with the reason (wellhead above the curve's maximum, column heavier than the reservoir, or unable to sustain its minimum stable rate). Gas lift: injection rate (Sm³/d) and depth along the tubing, optionally the lift gas gravity (black-oil) or mole fractions (compositional); the lift gas joins the produced fluid at the valve and leaves at the wellhead node.

Inside the Edit Components dialog you can reorder devices with the ↑ and ↓ buttons, and delete individual devices with the Delete button. All these actions are undoable.

After a successful solve, double-click any link to see how pressure evolves along it, with each device labelled. Pipes appear as sloped lines; fittings, pumps, chokes and valves appear as vertical pressure steps, marked with ×.

Configuration

Settings panels

Global settings live in the menu bar; the left sidebar summarises the current choices.

  • Physics → Case Type Picks the model for the whole network. Incompressible liquids can be solved isothermal or non-isothermal (temperature solved with the flow). Compressible is for gas (density from the ideal-gas law or Peng-Robinson). Black-oil (3-phase) handles oil, gas and water with PVT correlations. Compositional (EOS) handles a mixture of named components with an equation of state, including free water. The last three always solve temperature.
  • Material → Define Material The dialog depends on the case type.

    Incompressible and compressible cases — Library (water), Custom (density and viscosity; add cp and k for heat transfer), Crude oil (API gravity and temperature, Beggs-Robinson dead-oil viscosity), Gas (ideal) (molecular weight) and Gas (PR) (critical temperature, critical pressure, acentric factor). For water and crude oil, the Temperature-dependent properties box makes density, viscosity, cp and k follow the local temperature.

    Black-oil — API gravity, gas gravity, PVT correlation set and gas thermal properties. GOR and WOR are given per source node.

    Compositional — component names (for example methane, ethane, propane, water), default mole fractions and the equation of state (Peng-Robinson or SRK). Each source node then sets its own composition.
  • Physics → Pressure-Drop Model Turbulent friction for pipes: Colebrook-White (default, any fluid), Hazen-Williams (water distribution), Weymouth, Panhandle A and Panhandle B (gas transmission), and Beggs-Brill (two-phase flow with liquid holdup, flow pattern and the inclination correction; optionally with the holdup factors attributed to Payne, which are unverified; black-oil and compositional cases).
  • Numerics → Define Numerics Controls solver behaviour. Key settings:

    Laminar / Turbulent iterations — number of outer pressure-correction iterations in each phase. The laminar phase seeds the velocity field; the turbulent phase continues until convergence or the iteration limit.

    Pressure relaxation (α) — under-relaxation factor applied to each pressure correction. Values close to 1 converge faster; values closer to 0 are more stable for stiff networks. Default: 1.0.

    Velocity loop and Friction factor — inner loop solvers (method + max iterations + tolerance) for computing V* and f at each outer iteration. Fixed-point and Newton methods are available.

    Isothermal at (°C) — compressible, black-oil and compositional cases: leave blank to solve the energy equation; enter a temperature to hold every node, pipe, separator and well tubing at it. No fixed-temperature boundary is needed then, and the warnings list what has no effect (heater duties, compressor heating, Joule-Thomson change across valves, heat exchange of wells with the formation).

    Convergence criteria — the outer loop is considered converged when both the absolute pressure correction (Pa) and the relative nodal mass imbalance |ṁin − ṁout| / (ṁin + ṁout) fall below their respective tolerances.
  • Studies → Sensitivity / Nodal Analysis Sensitivity varies one boundary or component parameter over a range and plots a flow or a pressure (non-converged points are listed). Nodal Analysis splits the network at a well's wellhead and plots the well's inflow curve against the outflow curve of the rest of the network; they cross at the operating point the network solve gives. The same studies are available from Python in angelica.studies.
  • Settings → Unit System SI (m · Pa · kg/s), US customary (ft · in · psi · lb/s) or oil field (psia · °F · ft · in · lb/s; temperatures in °F). Black-oil and compositional results also carry standard-volume rates per connection (Sm³/d, STB/d, MMscf/d, bbl/d at 60 °F and 1 atm) in the CSV and Excel exports. The choice applies both to the values shown on the canvas and to the pressure, flow, length, diameter, roughness and elevation fields you type in; Angelica stores everything in SI.
  • View Dark or light theme, and the convergence window.

Simulation

Running a simulation

  1. Build the network on the canvas (nodes + links + devices).
  2. Choose the case type, then set the material, pressure-drop model, and any numerics settings you want to change from their defaults.
  3. Press the Run button at the top of the left panel.
  4. Angelica validates the scene first: it checks that all nodes are connected, that the graph has no isolated sub-networks, and that at least one pressure boundary exists. Any errors are shown in a dialog before the solve begins.
  5. The solver runs the laminar-phase iterations followed by the turbulent-phase iterations. A progress bar and live convergence metrics are shown during the solve.
  6. Results appear on the canvas: every node shows its pressure (and temperature, in thermal cases), and boundary nodes show the computed flow rate. In compositional cases each link is labelled with its vapour fraction, and two-phase links are drawn in amber. The convergence history plot opens automatically during the solve and can be reopened at any time from View → Convergence Window.
  7. Right-click any link for its pressure and temperature profiles and, in compositional cases, its phase envelope.
  8. Use File → Save (Ctrl+S) to persist the scene and results. Reopening the file restores the last solve output, so File → Export Results Report (Excel or CSV) works immediately without re-running.
If the solver does not converge, try reducing the pressure relaxation factor α (e.g. to 0.5) in the Numerics panel and increasing the turbulent iteration count. Stiff networks with highly varying pipe diameters often need lower relaxation.

A run that does not converge (black-oil and compositional) opens a message saying where it is stuck: the criteria not met, the node with the largest mass imbalance, and any pipe whose flow pattern (Beggs-Brill) or regime (laminar / turbulent) keeps alternating. Such a pipe sits on a boundary where the pressure-drop law jumps, so it may have no solution at that flow; changing the relaxation will not help, changing its diameter or the boundary pressures will.

Warnings appear in the status bar and in the exported report even when the run converged: for black-oil, the dead-oil viscosity (Beggs-Robinson) used outside its data range of 21.1–146.1 °C (70–295 °F) or 16–58 °API — below that range it is extrapolated and may overstate the viscosity — and nodes cut off by closed regulators, whose reported pressure is arbitrary.

Tutorials

Built-in tutorial cases

Angelica ships with fifty-one tutorial cases in five folders under tutorials/: isothermal (11), non-isothermal (8), compressible (6), compositional (11) and black-oil (15). Each case includes a .gui.json file you can open directly in the GUI, and a run.py script that solves the same network from Python. Open them via File → Open.

Within each folder the cases are ordered by increasing complexity.

01

Pipe-only network

A branched network of six pipes with two pressure-specified sources and one pressure-specified sink. No fittings or pumps. Good starting point — demonstrates how to build a network, set boundary conditions, and interpret the pressure field at each junction.

02

Fittings — no elevation

Introduces fitting (minor loss) devices in a flat network. Shows how to add a fitting in series with a pipe inside the same link, and how to set the K-loss coefficient.

03

Fittings — with elevation

Same topology as Tutorial 02 but with non-zero height changes on pipes and fittings. Demonstrates that the hydrostatic term ρgΔz is handled automatically once height_change_m is set on each device.

04

Flow-specified inlet

A source boundary with a specified mass flow rate (instead of pressure). Requires at least one pressure-specified boundary elsewhere in the network to anchor the pressure level.

05

Flow-specified outlet

A sink boundary with a specified mass flow rate. Mirrors Tutorial 04 from the outlet side.

06

Mixed boundary conditions

A network with both flow-specified and pressure-specified sources and sinks active simultaneously. Demonstrates that multiple boundary-condition types can coexist in the same network.

07

Hanoi network benchmark

The classic Hanoi network introduced by Fujiwara & Khang [6], solved with Hazen-Williams (C = 130), matching the original problem formulation. Nodal heads and link flows are compared against reference values computed by this solver and verified for physical consistency. This is the primary validation case for the pipe solver on a large, multi-loop network.

08

EPANET pump benchmark

A pump-bearing network adapted from the official EPANET tutorial. Validates the pump curve model (quadratic head-vs-flow fit) against the EPANET reference solution.

09

Three-reservoir junction

Classic Y-junction problem: three fixed-head reservoirs connected at a common node. Junction head and pipe flows are compared against an independent analytical solution computed by bisection over the Colebrook-White equation. Agreement is within 0.001 m³/h on all flows.

10

Laminar Poiseuille benchmark

Three smooth parallel pipes carrying viscous oil (Re < 180). Volumetric flows are compared against the exact closed-form Hagen-Poiseuille solution Q = πD⁴ΔP / (128μL). Maximum relative error is below 0.001 % — confirming that the solver handles the laminar regime correctly.

11

Crude oil gathering pipeline

A branched steel pipeline carrying 32°API dead crude at 65°C. Fluid density and viscosity are computed automatically from API gravity and temperature via the Beggs & Robinson (1975) correlation — no manual property look-up required. All three pipes operate in the fully turbulent regime (Re = 19 000–31 000), solved with Colebrook-White friction.

Compositional tutorials

Physics mode Compositional. The material is a list of components with mole fractions; each source can carry its own composition. Right-click a connection for its phase envelope.

01

Compositional Single Pipe

A single gas pipe transporting a methane/ethane binary mixture. The EOS flash is performed at each iteration using the thermo library, showing how density and viscosity change along the pressure gradient.

02

Compositional Gas Mixing Junction

Two gas sources with different compositions feed a common trunk line. The solver propagates each inlet's mole-fraction vector through the network and computes a molar-flow-weighted blend at the junction.

03

Compositional Looped Gas Network

Two gas sources with different compositions feed a looped gathering network. The loop creates a hydraulic cycle — the SIMPLE solver distributes flow to satisfy mass balance at every node and Kirchhoff's pressure law around the loop.

04

Free Water in a Wet-Gas Pipeline

Demonstrates Angelica's immiscible-water model. When water is included in the component list the solver detects it automatically, performs the VL flash on the dry (water-free) normalised composition, and determines how much water condenses as free liquid using the Wagner / IAPWS-IF97 saturation pressure.

05

Three-Phase Rich Condensate Pipeline

Demonstrates a three-phase result: Gas + HC liquid + Free water.

06

Compositional Ring Main: Who Gets the Condensate?

Two gas fields feed a ring main that supplies two customers. Each source enters the ring at one corner and each customer draws from another corner, so every customer is fed by both sources along two different paths.

07

Hilly Gas-Condensate Line: Homogeneous vs Beggs-Brill

A wet gas crosses 20 km of hilly terrain. With Beggs-Brill the gas slips past the liquid: the line holds about 126 m³ of liquid instead of 24 m³, and delivers 15.6 % less gas for the same pressures than the homogeneous model.

08

Hydrate Risk in a Subsea Wet-Gas Line

A wet gas flows 30 km along a 4 °C seabed. Bare, it enters the hydrate region after 5 km and arrives 15 K inside it; insulated, it arrives 3 K above the hydrate formation temperature. Shows the hydrate curve (structure II with 3 % propane) and the per-pipe hydrate margin.

09

Gas and Gas-Condensate Wells

A lean-gas well and a gas-condensate well produce through 3.0–3.2 km of tubing into a manifold. Shows the deliverability curves with standard gas and condensate rates, the gas cooling on the drawdown, liquid condensing up the tubing, and the condensate well — with the heavier, liquid-laden column — dying first when the separator pressure rises.

10

Separator Train

A volatile oil with free water goes through a high-pressure separator (gas to export, water to disposal) and a low-pressure stage to the stock tank. Shows the optimum separator pressure for stock-tank liquid and the extra liquid a second stage recovers.

11

Pressure-Reducing Station

A natural gas is let down from a 20 km transmission line to a 20 bar distribution network by a pressure-reducing regulator. Shows the Joule-Thomson cooling across the regulator, the preheating that keeps its outlet above 0 °C, and the supply pressure below which the regulator is wide open.

Black-oil tutorials

Physics mode Black-oil. The material gives API and gas gravity; each source node sets its GOR and WOR (and optionally its own API and gas gravity).

01

Black-Oil Three-Phase Pipeline

A single-pipe crude-oil system with dissolved gas and produced water.

02

Black-Oil Looped Gathering Network

A trunk-fed diamond loop. A single header feeds a T-split junction; two parallel loop branches reconnect at a T-merge junction; a single discharge header leads to the outlet separator.

03

Black-Oil Looped Network with Flow Outlet

Trunk-fed diamond loop where the outlet specifies a mass-flow demand instead of a pressure. The solver finds the outlet pressure that satisfies the 100 kg/s demand.

04

Black-Oil Looped Network with Two Separators

Trunk-fed diamond loop with a lateral branch to a satellite separator. The main loop converges at Node 5 (T-merge), which leads via a discharge trunk to the primary separator (Node 6, 80 kg/s). A lateral branch from Node 4 (lower loop junction) delivers crude to a satellite separator (Node 7, 20 kg/s).

05

Black-Oil Two-Reservoir Blending

Two reservoirs with different fluid properties (API gravity, GOR, WOR) feed a common trunk that delivers to a single separator. Each inlet carries its own composition; the solver propagates and mixes them at the junction.

06

Black-oil gathering network with topographic elevation

Demonstrates the elevation source term ρ_mix·g·Δz in a three-phase system where the two wells are at very different elevations. Well A flows downhill (gravity assists), Well B flows uphill (gravity opposes) to reach the manifold.

07

Non-Isothermal Black-Oil Hot-Oil Pipeline

A heated crude-oil pipeline where temperature-dependent PVT properties (viscosity, density, solution GOR) materially affect the hydraulic result.

08

Beggs-Brill two-phase flow correlation

Compares two pressure-drop models on the same horizontal 10 km black-oil pipeline. Single-phase Colebrook-White ignores slip and holdup and over-predicts the flow by about 23 % relative to Beggs-Brill two-phase flow.

09

Beggs-Brill in a multi-well gathering network

Three production wells with different fluid characteristics (GOR, API, water cut) converge at a single manifold and then flow to a separator.

10

Critical two-phase flow through a production choke

A choke (bean) is the primary flow-control device on a production well. When the pressure ratio across it falls below a critical value, the gas-liquid mixture reaches sonic velocity in the throat and the flow becomes "choked": the rate no longer depends on what happens downstream.

11

Wells with inflow performance (IPR) and check valves

Tutorial 09 fixed each well's pressure at the wellhead, so the weakest well took back-flow from the manifold. Here each well is a reservoir that delivers oil according to its inflow performance relationship (IPR), and a check valve at each wellhead stops back-flow.

12

Wells with production tubing (nodal analysis in a network)

Tutorial 11 referred each well's inflow to the wellhead. Here every well carries its production tubing: 2 100 m of tubing rising 2 000 m from the bottom hole to the wellhead. The Well component combines the reservoir inflow (IPR) and the tubing, so the network sees each well through its deliverability curve P_wh(q). The tubing temperature profile is solved too: each well reaches the network at its flowing wellhead temperature.

13

Gas Lift

A heavy, wet crude whose column outweighs the reservoir is brought to life by injecting gas into the tubing. Shows the gas-lift performance curve — oil rate rises with injection, peaks near 70 000 Sm³/d and then falls as friction wins — the effect of the injection depth, and the tubing profile with the injection point.

14

Three-Phase Separator

Two wells deliver to a production separator whose pressure follows from the gas export line; oil and water leave through level-control valves to the stock tank and disposal. Shows the split, how the export pressure sets the separator pressure and the wells' rates (up to wells dying by back-pressure), a liquid line too small for its flow, and an export pressure at which the oil line has no solution.

15

Back-Pressure Regulator

The network of tutorial 14 with a back-pressure regulator on the separator's gas line. Shows the separator held at its set pressure whatever the export pressure below it, the regulator opening above it, and what a higher separator pressure costs in production.
