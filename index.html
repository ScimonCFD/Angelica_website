Why Angelica

Built differently.

Free. Permanently.

MIT license. Use Angelica in commercial projects, academic research, or internal tooling without fees, expiry dates, or usage limits. The code is yours — read it, modify it, ship it.

Accuracy you can verify.

Every result is benchmarked against published EPANET reference solutions. The solver's performance is documented, reproducible, and open to inspection — not a black box.

An architecture with a plan.

Isothermal, non‑isothermal, compressible, and black‑oil three‑phase solvers are all live. Compositional multicomponent simulation is next — each stage built on the same validated foundation.

The workflow engineers already know.

Define sources and sinks, connect them through junctions, assign components, and run. No scripting, no configuration files, no setup rituals. From network to results in minutes.

Capabilities

A complete toolset for pipe network engineering.

Pipes

Darcy-Weisbach with Colebrook-White or Hazen-Williams closure. Arbitrary length, diameter, and wall roughness.

Fittings

Local-loss accessories from a built-in library or a custom K. Elbows, valves, tees, and any fitting with a known loss coefficient.

Pumps

Single-point EPANET model and piecewise-linear multi-point curves. Operating point computed directly from the required head.

Non-isothermal flow

Heat loss along pipes via the NTU method. Inline heaters and coolers with fixed thermal power. Temperature-dependent fluid properties (ρ, μ, cp). Pressure and temperature profiles per link.

Boundary conditions

Pressure and mass-flow boundaries on any node. Mixed types — sources, sinks, flow inlets, flow outlets — on the same network.

Graphical interface

Build and edit networks without writing code. Inspect convergence, review nodal and link results, and export a spreadsheet report.

Fluid properties

Water (library preset) or any liquid with custom density and viscosity. Crude oil: enter API gravity and operating temperature — density and viscosity are computed automatically via Beggs & Robinson (1975).

Open source

Full source on GitHub under the MIT license. No subscriptions, no license fees, no vendor lock-in. Use it, fork it, extend it.

Accuracy you can check.

Hanoi benchmark

Hazen-Williams (C = 130) on the 32-node Fujiwara & Khang [6] network.

max head error < 0.01 m across all 32 nodes

EPANET pump benchmark

Pump-bearing network from the official EPANET tutorial [5].

pressures within 0.15 psi of published reference

Three-reservoir junction

Y-junction against an independent bisection + Colebrook-White reference — no external solver.

all flows agree to within 0.001 m³/h

Laminar Poiseuille benchmark

Three pipes (Re < 180) against the exact closed-form Q = πD⁴ΔP / (128μL).

max relative error 0.0000 %

NTU pipe heat loss — analytical

Single pipe with ambient loss against the exact Tout = Tamb + (Tin − Tamb) e−NTU.

Tout exact — NTU formula applied directly

Cengel & Ghajar Example 8-3 [9]

Dead crude oil in an icy lake — textbook h from Gnielinski, given to Angelica as fixed overall U.

Texit = 19.74 °C, within 0.05 K of textbook

Compressible — P¹²−P²² mass flow

Isothermal air in a single pipe (D = 50 mm, L = 100 m) against the exact P12−P22 + Colebrook-White analytical reference.

ṁ agrees with analytical within 0.01 %

Compressible — series-pipe midpoint pressure

Two identical isothermal air pipes in series. Exact result: Pmid = √((P12 + P22)/2) — a consequence of the P2 momentum equation.

Pmid within 500 Pa of √((3002+1002)/2) = 223.6 kPa

Compressible — gas pipe heat loss NTU

Compressible air with wall heat loss (U = 5 W/m²K, Tin = 80 °C, Tamb = 20 °C) against the exact NTU exit temperature.

Tout exact to machine precision — NTU formula applied directly

Black-oil — three-phase pipeline

32 °API crude, GOR = 25 m³/m³, WOR = 0.5. Single 10 km pipe, 8 MPa → 2 MPa. Bubble point = 5.63 MPa: inlet is undersaturated, outlet is two-phase. PVT correlations: Standing, Hall-Yarborough, Beggs-Robinson, Lee-Gonzalez-Eakin, McCain.

Converges in 2 PVT iterations  ·  GOR/WOR recover exactly from surface mass balance

Black-oil — looped gathering network

Two parallel flow paths (upper: 10 km; lower: 11 km) between a single inlet and a separator. Upper junction sits just above the bubble point (undersaturated); lower junction falls below it (two-phase). Mixture expands along the upper path as free gas liberates from solution.

62.7 % flow upper path  ·  37.3 % lower  ·  converges in 3 PVT iterations

Linux  ·  macOS

Install with pip

Requires Python 3.8 or later. Run the two commands below in a terminal:

pip install git+https://github.com/ScimonCFD/Angelica.git
angelica-gui

Core dependencies: numpy and scipy. GUI extra (.[gui]) adds sv‑ttk; Excel export (.[excel]) adds openpyxl.
